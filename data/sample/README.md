# Sample Data

This directory contains fallback and sample data for offline or demo use.

| File | Provenance | Origin Tag | Description |
|---|---|---|---|
| `synthetic_mandi_prices.csv` | Generated by `generate_synthetic_data.py` (Rule-based simulation) | `synthetic` | Simulated prices/arrivals with injected defects. |
| `synthetic_weather.csv` | Generated by `generate_synthetic_data.py` | `synthetic` | Simulated weather data with rain shocks. |

All files here are synthetic and should never be presented as real data.
